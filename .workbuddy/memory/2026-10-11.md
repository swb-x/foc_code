# 2026-10-11

## 修复 TIM1 六路 PWM 只有三路输出的问题（STM32G431C8T6，DRV8353）

- 根因：`motor/mcpwm_foc.c` 的 `start_pwm_hw()` 只置位了 `CC1NE|CC2NE|CC3NE`，**从未置位 `CC1E|CC2E|CC3E`**。
  工程未调用 `HAL_TIM_PWM_Start()` / `HAL_TIMEx_PWMN_Start()`，而 `MX_TIM1_Init()` 中的
  `HAL_TIM_PWM_ConfigChannel() -> TIM_OCx_SetConfig()` 会显式清零 CCxE 与 CCxNE（HAL 源码 7169/7194 行）。
  结果只有 PA7/PB0/PB1（CH1N/2N/3N）有 PWM，PA8/PA9/PA10（CH1/2/3）高阻。
- 修复：
  1. `start_pwm_hw()` 同时置位 CC1E/CC2E/CC3E + CC1NE/CC2NE/CC3NE。
  2. `Motor_PWM_Test50()` 中在 `__HAL_TIM_ENABLE` 后加 `TIM1->EGR |= TIM_EGR_UG`（CCR 有 OCxPE 预装载）。
  3. `mcpwm_foc.h` 的 `TIMER_UPDATE_DUTY_MT` 修正 CCR2/CCR3 参数错位（原来 CCR2=duty3、CCR3=duty2），
     并加 `do{}while(0)` 包裹。
  4. 从头文件中移除 `static` 函数声明（会导致未定义告警），改在 .c 顶部前向声明。
- 已知遗留：`stop_pwm_hw()` 关断时互补通道为高阻（OSSR/OSSI=DISABLE），
  若栅极驱动输入无下拉，建议改成 CCxE/CCxNE 全置 1 + OCxM=011。
- TIM1 配置：中心对齐模式3，ARR=4249，死区 50，MOE 由软件手动开启（AOE=DISABLE）。
  CH4 被配成 TRGO(OC4REF) 但 CCR4=0 且未启动，当前未用作 ADC 触发（ADC 为软件触发）。

## 项目约定
- 主控 STM32G431CBT6，栅极驱动为 **DRV8323RS**（非 DRV8353，代码注释勿再写错）。
- EN_GATE = PA6（宏 ENABLE_Pin），nFAULT = PA5；EN_GATE 低电平驱动器休眠，无任何栅极输出。
- 板上注意事项（原理图自带）：IDRIVE 电阻 R22/R33 只焊一个（接 DVDD=Disabled），VDS 电阻 R23/R34 只焊一个（接 AGND）。
- PWM 通道映射：PA8=CH1, PA9=CH2, PA10=CH3, PA7=CH1N, PB0=CH2N, PB1=CH3N（AF6），六路 GPIO 均在 `HAL_TIM_MspPostInit` 中配置。
- PWM 启停不依赖 HAL 的 Start 系列函数，直接操作 CCMR/CCER/MOE，改动时需自己保证 CCxE/CCxNE 状态一致。

## 晚间追加：MCU 六路 PWM 正常但 DRV8323 无输出
- 根因：`Motor_PWM_Test50()` 中 EN_GATE 拉高的代码被注释掉，PA6 初始化又为低，DRV8323 一直处于休眠。
- 修复：恢复 EN_GATE 拉高 + osDelay(2) + nFAULT 低电平故障检查打印（`motor/mcpwm_foc.c`）；
  `gpio.c` 中 nFAULT 改为内部上拉（nFAULT 是开漏输出）。
