## 工程编码约定（必守）

- `Core/` 与 `motor/` 下所有含中文注释的 `.c/.h` 必须保存为 **GBK 编码**。
- 原因：用户用 MDK Keil 编译/查看代码，Keil 对无 BOM 的 UTF-8 按本地代码页（GBK）解读，会显示为乱码。
- 修复/统一脚本：`C:\Users\a2025625\Desktop\Foc\.workbuddy\to_gbk.py`（会把 Core/ 与 motor/ 下含非 ASCII 的源文件统一转 GBK，并顺带修复已知损坏文本）。
- **每次用 Write/Edit 工具改过这些文件后，都要重跑一次该脚本**，否则新写入的内容会变回 UTF-8。
- 注释里不要使用 GBK 不支持的字符：`µ`(U+00B5，用 `u` 或 `μ` 代替)、`⚠️`(U+26A0/U+FE0F，用【注意】代替)。`α β λ ≈ ± × → ℃ ≥ ≤` 等 GB2312/GBK 都支持，可以正常用。
