## 本轮修复：上电后 LED 不闪 / 串口再无输出（系统死机）

- 现象：三个任务启动消息全部打出来（串口输出交错），之后无任何输出（温度行、ADC2 timeout 都没有），LED 不闪。

  → 破坏相邻内存 → HardFault → 全系统停摆。heap 3KB 也已贴上限（Idle 512B + Timer 任务 1KB + 3 用户任务）。
- 已改：
  1. FreeRTOSConfig.h：configTOTAL_HEAP_SIZE 3072→10240（注意：CubeMX GUI 项，重生成会覆盖，需同步改）；
     USER CODE Defines 区加 configCHECK_FOR_STACK_OVERFLOW=2、configUSE_MALLOC_FAILED_HOOK=1（USER CODE 区安全）。
  2. app_freertos.c：三个任务 stack_size 128*4→256*4（GUI 项，重生成覆盖）；USER CODE 1 区实现
     vApplicationStackOverflowHook / vApplicationMallocFailedHook（打印+关中断死循环）。
  3. it.c：HardFault_Handler 的 W1 USER CODE 区加 LED 高速闪烁（快闪=HardFault，区别于正常 500ms 慢闪）。
- 串口并发交错未修（不影响功能），如需整洁建议应用层做 vsnprintf+临界区一次性发送的 log_printf。

## 栅极驱动波形分析（未改代码，仅诊断）

- 现象：上管驱动 22V、下管 11V（差一倍）；上管关断有米勒平台；上管未完全关断下管已导通。
- 结论1（22V 正常）：高侧 GHx 相对 **SHx 相节点**（浮地）驱动，单端探头量 GH–GND = 相节点电压 + 驱动幅值(≈11V)。
  SH=11V 时 GH–GND=22V。正确量法：差分探头量 GH–SH、GL–PGND。待确认母线实际电压。
- 结论2（米勒平台）：t_platform ≈ Qgd / I_drive，平台达几百 ns ⇒ DRV8323 的 IDRIVE 档位太低
  （原理图 R22/R33 二选一焊接决定）或外部栅极电阻过大。
- 结论3（直通，危险）：TIM1 DeadTime=10，TIM1 时钟 170MHz（APB2 不分频）⇒ 死区仅 58.8 ns。
  对比：10-11 版本曾是 DeadTime=50（≈294ns），被改小后安全余量没了。
  DRV8323 内部 handshake 死区约 100ns，仍盖不住米勒平台 ⇒ 出现交叠，母线直通。
  直通会触发 VDS OCP → nFAULT 拉低（可能就是前期"驱动端无输出"的诱因之一）。
- 建议（待用户确认后动手）：DeadTime 改 60~85（350~500ns）；查 R22/R33 实际阻值对照手册选更大 IDRIVE；
  查外部栅极电阻值；用差分探头量 GH–SH 并看母线电流尖峰验证。
  调试期务必低压限流，确认无交叠再加负载。

## 硬件参数确认后的量化复核（母线 12V / R23=R34=75K / MOS=CSD19532Q5B）

- 22V 之谜**完全闭合**：DRV8323 低侧 VGLS 固定 11V（线性稳压）；高侧 VCP = VVM+11V，
  但 VVM<12V 时电荷泵转全倍压模式 VCP=2×VVM−1.5=22.5V ⇒ GH−SH ≈ 10.5V。
  单端量 GH–GND = SH(12V) + 10.5V ≈ 22.5V，实测 22V ⇒ **完全正常，是测量方式假象**。
- 关键参数（已查证）：
  - CSD19532Q5B：Qg=48nC、Qgd=8.7nC、Qgs=13nC、Vth=2.6V、Rds(on)=4mΩ@10V（100V/140A 器件）。
  - DRV8323 硬件版 7 档 IDRIVE：AGND=10/20mA，18k→AGND=30/60mA，**75k→AGND=60/120mA**，
    HiZ=120/240mA，75k→DVDD=260/520mA，18k→DVDD=570/1140mA，DVDD=1A/2A。
    同脚 VDS 阈值对应：0.06 / 0.13 / **0.26** / 0.60 / 1.13 / 1.88V / 禁用。
  - DRV8323 硬件版最小死区 **100ns**（独立模式 Independent PWM 完全无死区插入、无防直通）。
- 量化结论（按 IDRIVE=75k→AGND 即 60/120mA 算）：
  - 关断延迟：Vgs 11V→平台约 26nC/120mA≈217ns + 米勒平台 8.7nC/120mA≈72ns ≈ **290~300ns** 才降到 Vth。
  - 可用死区 58.8ns(TIM1) / 100ns(DRV8323 下限) ⇒ **直通窗口约 200ns**。
  - 更糟：VDS 阈值 0.26V ÷ 4mΩ = 65A 才动作，直通峰值（受回路 L 限制约几十 A）达不到 ⇒
    **OCP 根本不会报，管子默默发热**。这与"驱动端无输出/nFAULT 不报"的现象并不矛盾。
- 用户已确认：**VDS = 75K 下拉（→AGND）、IDRIVE = 75K 上拉（→DVDD）**
  ⇒ IDRIVE = **260mA 拉 / 520mA 灌**（偏高档）；VDS 阈值 = **0.26V**。
- 复核关断延迟（520mA 灌）：(Qg−Qgs)≈35nC / 520mA ≈ **67ns**，米勒平台仅 ~10ns（12V 母线 Qgd 远小于
  手册 50V 条件下的 8.7nC）。DRV8323 最小死区 100ns ⇒ 6x 模式下**不会有真直通**（余量约 33ns）。
- **因此观测到的"平台 + 交叠"改判为单端测量假象**：GH–GND = SH + (GH−SH)。高侧关断后 GH−SH 已归零，
  但死区内 SH 仍挂在 12V（相电流方向决定是保持 12V 还是被体二极管拉到 −0.7V），
  直到下管导通把 SH 拉到 0 ⇒ GH–GND 停在 12V 形成"平台"，且正好与下管开通重叠 ⇒ 看起来像直通。
  **验证方法：差分探头量 GH–SH，或两路普通探头做 A−B。**
- 由确认后的档位引出的新问题（真实存在，非假象）：
  1. 260mA 驱 48nC 太快：Vds 转换仅 ~17ns ⇒ dV/dt 约 600V/µs，必然严重振铃 + dV/dt 寄生导通，
     TI 对大 Qgd 管子建议降档并加栅极电阻。必要时 IDRIVE 降到 Hi-Z(120/240mA) 或 75k→AGND(60/120mA)。
  2. VDS 0.26V ÷ Rds(on)4mΩ = **65A 才动作**，对这个 4mΩ 管子等于过流保护基本失效；
     建议换 18k→AGND(0.13V≈33A) 或直连 AGND(0.06V≈15A)，或改用 SEN_OCP（采样电阻）做过流。
  3. MODE 脚必须再确认：若为 Independent（MODE 接 DVDD）则无死区插入、无防直通，
     只剩 TIM1 的 58.8ns < 67ns ⇒ 真直通。6x 模式要求 MODE 接 AGND。
- 待用户确认后再动手改 DeadTime（当前 tim.c DeadTime=10 即 58.8ns，偏紧）。
